# 감성 라벨링 업그레이드 분석 — 단어사전 → LLM

> 작성일: 2026-06-19 · 대상: 시가총액 상위 200종목 · 토론(GPT) 없이 검색만 측정

## 1. 배경 & 목표

기사 선정에서 호재/악재를 가르는 **감성 점수**를 두 가지 방식으로 비교한다.

- **OLD (단어사전)**: `rag/sentiment.py` — 호재/악재 단어 개수를 세서 채점. 무료·즉시, 단 사전에 없는 표현은 놓침.
- **NEW (LLM 라벨)**: `collection/sentiment_labeler.py`로 gpt-4o-mini가 기사 맥락을 읽어 채점, `articles.sentiment`에 저장(19,746건 100% 완료). 검색 시 `_get_sentiment`가 이 값을 우선 사용.

**핵심 목표**: 단어사전이 못 잡는 미묘한 악재를 LLM이 포착해, **bear(악재) 측 기사가 비는 종목**을 줄인다.

> 검색 로직(별칭·최신풀·제목필터·유사도)은 동일하고 **감성 점수 산출만** 다르게 두어 순수 비교.

## 3. 무엇이 좋아졌나 — 실제 사례

### ✅ 단어사전이 놓친 악재를 LLM이 포착

| 종목 | 기사 | OLD | NEW |
|:---|:---|:---:|:---:|
| **KT** | "25년 독점권 믿고 들어갔는데… KT 르완다 4G 합작사업 **철수**" | 못 잡음(0건) | **−0.80** |
| **POSCO홀딩스** | "포스코야마토비나, 중국산 철강 **반덤핑** 연장 청구" | 못 잡음(0건) | **−0.40** |

→ "철수", "반덤핑" 같은 표현은 단어사전에 없어 OLD는 중립(0)으로 흘려보냈지만, LLM은 맥락으로 악재를 잡아 bear를 채웠다.

### 부수 효과: 모든 기사가 LLM 정밀 점수 사용
100% 라벨 완료로, 평소 검색은 단어사전이 아니라 LLM 점수를 쓴다 (단어사전은 새로 크롤링한 미라벨 기사의 폴백으로만 동작).

## 4. 한계 & 주의 (정직한 평가)

### ⚠️ 개선폭은 기대보다 작다 (bear 빈 81→72)
남은 빈 종목 대부분은 **감성 판별 실패가 아니라 "악재 기사가 데이터에 실제로 없는"** 종목이다. 지금 시장이 호재 분위기라, LLM이 아무리 잘 읽어도 없는 악재를 만들 수는 없다 → 감성 모델로 더 줄이기 어려운 한계.

### ⚠️ LLM이 빈 칸을 "무관/약한 기사"로 채우기도 함
- **효성 bear (NEW)**: "강남원**효성**빌라 재건축 판단 보류" −0.50 → 제목에 '원효성'이 들어가 ticker가 잘못 매칭된 **부동산 기사**를 LLM이 악재로 채움. 효성(기업)과 무관.
- 즉 NEW가 bear를 채운 27종목 중 일부는 **노이즈로 채워진 것**일 수 있어, "빈 종목 감소"가 곧 "품질 향상"은 아니다.

### 결론
| 항목 | 평가 |
|:---|:---|
| 미묘한 악재 포착 | **개선됨** (KT 철수, POSCO 반덤핑 등) |
| bear/bull 빈약 | 줄었으나 드라마틱하진 않음 (데이터 한계) |
| 호재/악재 분리 정확도 | 0% 오분류 유지 |
| 새 리스크 | 잘못된 ticker 매칭 기사를 LLM이 악재로 채울 수 있음 |

**총평**: LLM 라벨링은 감성 품질을 한 단계 끌어올렸고(특히 사전에 없는 표현), 모든 기사가 정밀 점수를 쓰게 됐다. 다만 남은 빈약 종목은 데이터 자체의 한계이며, 일부는 크롤링 단계의 ticker 부정확이 원인이라 감성 모델 밖의 문제다.
